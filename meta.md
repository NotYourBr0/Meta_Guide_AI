# Meta Guide AI - System Architecture & Meta Info

## Overview
Meta Guide AI is an intelligent educational platform that allows users (specifically targeting RTU syllabus) to explore subjects, read explanations, take tests, and track their scores. It uses an AI-powered process to generate topic explanations and question banks.

## Stack Architecture
### Frontend (React + Vite)
- **Framework**: React 19 / Vite
- **Routing**: `react-router-dom`
- **Styling**: TailwindCSS
- **State Management**: React Context / Hooks
- **Authentication**: JWT & `@react-oauth/google` for Google Sign-In
- **Localization**: `i18next`
- **Markdown Rendering**: `react-markdown` with `rehype-katex` & `remark-math` for math formulas
- **Animation**: `framer-motion`

### Backend (Node.js + Express)
- **Framework**: Express.js
- **Database**: MongoDB via Mongoose
- **Authentication**: JWT & `google-auth-library`
- **Security**: `cors`, `bcryptjs`, `cookie-parser`
- **Utilities**: `node-fetch`, inline generation logic using AI models (simulated or real).

## Core Features
### User Authentication
- Regular Signup / Login with Email and Password (hashed via bcrypt).
- Google Authentication support.
- Protected routes using JWT tokens.

### Subject & Topic Exploration
- **Subjects**: Represents high-level courses (e.g., RTU courses). Includes validation against RTU Syllabus.
- **Topics**: Represents individual study modules within a subject. Organized by difficulty (beginner, intermediate, advanced).
- **Topics Generation**: Topics trigger an asynchronous background task to fetch or generate content, simulating AI fetching mechanisms.

### Tests & Question Banks
- Automatically generated question banks per topic (20 questions generated by default).
- Dynamic tests mapping to user levels (Beginner gets 5, Intermediate 5, Advanced 10 questions).
- High scoring system using maximum sums calculated per attempting level.

### Leaderboard & Gamification
- Tracks user’s high scores globally and per topic.
- Gamified engagement with user ranking shown dynamically.

### Admin Dashboard
- Private `/api/admin` routes checking for `role === "admin"`.
- Features to manage users, test records, subjects, and topic metadata.

### System Flow
1. **User lands & Authenticates**: Fetches JWT through Email or Google.
2. **Subject Dashboard**: Browses standard academic subjects.
3. **Topics Details**: Clicks into a Topic, views generated AI explanations.
4. **Action - Take Test**: The UI queries `/api/tests/questions/:topicId` which fetches from dynamically generated banks.
5. **Action - Result**: The score is submitted via POST `/api/tests/score/:topicId`. High score algorithms re-rank the user globally.
