## COURSE: 5CS3-01 — Information Theory & Coding

### 1. COURSE INFORMATION
- Course name: Information Theory & Coding  
- Course code: 5CS3-01  
- Branch: Computer Science and Engineering  
- Semester: V (III Year - V Semester)  
- Credits: 2  
- L-T-P structure: 2L + 0T + 0P  
- Max. Marks: 100 (IA:20, ETE:80)  
- End Term Exam: 2 Hours  
- Examination scheme / other details: As above.

### 2. COURSE OBJECTIVES
- Introduction: Objective, scope and outcome of the course.

### 3. COURSE OUTCOMES
- *No separate explicit course outcomes listed in the PDF beyond the "Objective, scope and outcome of the course" line.*

### 4. UNIT-WISE SYLLABUS

- **UNIT 1:** Introduction  
  - Topics:  
    - Objective, scope and outcome of the course.  
  - Details: "Introduction: Objective, scope and outcome of the course." (01 hour)

- **UNIT 2:** Introduction to information theory  
  - Topics:  
    - Uncertainty, Information and Entropy  
    - Information measures for continuous random variables  
    - Source coding theorem  
    - Discrete Memory less channels  
    - Mutual information  
    - Conditional entropy  
  - Details: Listed as "Introduction to information theory: Uncertainty, Information and Entropy, Information measures for continuous random variables, source coding theorem. Discrete Memory less channels, Mutual information, Conditional entropy." (05 hours)

- **UNIT 3:** Source coding schemes for data compaction  
  - Topics:  
    - Prefix code  
    - Huffman code  
    - Shanon-Fane code  
    - Hempel-Ziv coding  
    - Channel capacity  
    - Channel coding theorem  
    - Shannon limit  
  - Details: "Source coding schemes for data compaction: Prefix code, Huffman code, Shanon-Fane code & Hempel-Ziv coding channel capacity. Channel coding theorem. Shannon limit." (05 hours)

- **UNIT 4:** Linear Block Code  
  - Topics:  
    - Introduction to error connecting codes  
    - Coding & decoding of linear block code  
    - Minimum distance consideration  
    - Conversion of non-systematic form of matrices into systematic form  
  - Details: "Linear Block Code: Introduction to error connecting codes, coding & decoding of linear block code, minimum distance consideration, conversion of non-systematic form of matrices into systematic form." (05 hours)

- **UNIT 5:** Cyclic Code  
  - Topics:  
    - Code Algebra  
    - Basic properties of Galois fields (GF)  
    - Polynomial operations over Galois fields  
    - Generating cyclic code by generating polynomial  
    - Parity check polynomial  
    - Encoder & decoder for cyclic codes  
  - Details: "Cyclic Code: Code Algebra, Basic properties of Galois fields (GF) polynomial operations over Galois fields, generating cyclic code by generating polynomial, parity check polynomial. Encoder & decoder for cyclic codes." (06 hours)

- **UNIT 6:** Convolutional Code  
  - Topics:  
    - Convolutional encoders of different rates  
    - Code Tree, Trellis and state diagram  
    - Maximum likelihood decoding of convolutional code: The viterbi Algorithm  
    - Free distance of a convolutional code  
  - Details: "Convolutional Code: Convolutional encoders of different rates. Code Tree, Trllis and state diagram. Maximum likelihood decoding of convolutional code: The viterbi Algorithm fee distance of a convolutional code." (06 hours)

- Introduction: Objective, scope and outcome of the course.

### 3. COURSE OUTCOMES
- *Not separately listed.*

### 4. UNIT-WISE SYLLABUS

- **UNIT 1:** Introduction (01 hour)

- **UNIT 2:** Background & Divide and Conquer (06 hours)  
  - Topics: Review of Algorithm, Complexity Order Notations: definitions and calculating complexity. Divide And Conquer Method: Binary Search, Merge Sort, Quick sort and Strassen's matrix multiplication algorithms.

- **UNIT 3:** Greedy Method & Dynamic Programming (10 hours)  
  - Topics: Greedy Method: Knapsack Problem, Job Sequencing, Optimal Merge Patterns and Minimal Spanning Trees. Dynamic Programming: Matrix Chain Multiplication, Longest Common Subsequence and 0/1 Knapsack Problem.

- **UNIT 5:** Assignment Problems & Randomized Algorithms (08 hours)  
  - Topics: Formulation of Assignment and Quadratic Assignment Problem. Randomized Algorithms- Las Vegas algorithms, Monte Carlo algorithms, randomized algorithm for Min-Cut, randomized algorithm for 2-SAT. Problem definition of Multicommodity flow, Flow shop scheduling and Network capacity assignment problems.

- **UNIT 6:** Problem Classes (08 hours)  
  - Topics: Problem Classes Np, Np-Hard And Np-Complete: Definitions of P, NP-Hard and NP-Complete Problems. Decision Problems. Cook's Theorem. Proving NP-Complete Problems - Satisfiability problem and Vertex Cover Problem. Approximation Algorithms for Vertex Cover and Set Cover Problem.
